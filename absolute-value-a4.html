参考答案与解析第 3 题

第 3 题答案：1011 个 第 4 题答案：A（最小值为 c）

3.答案：1011 个。

【思路】绝对值的几何意义：|u−v| 表示数轴上点 u、v 之间的距离，把“解绝对值方程”变成“在数轴上找位置”。

第 1 步 · 把两个绝对值翻译成距离。把 2a 看成数轴上的一个动点 T：|1−2a|=|2a−1| 是 T 到定点 1 的距离；|2a+2020|=|2a−(−2020)| 是 T 到定点 −2020 的距离。方程的含义：T 到 1 的距离 + T 到 −2020 的距离 = 2021。

第 2 步 · 算两个定点的间距。1−(−2020)=2021，恰好等于方程右边的数！

第 3 步 · 距离和什么时候恰好等于 2021？只有 T 夹在 −2020 与 1 之间（含两端）时，两段路首尾相接、不多不少；一旦跑到两点外侧，就得“折返”，距离和 = 2021 + 2×跑出去的长度 > 2021。

图 1　2a 夹在 −2020 与 1 之间（含端点）时，两段距离之和恰好为 2021

所以 −2020 ≤ 2a ≤ 1。

第 4 步 · 数整数个数。两边除以 2：−1010 ≤ a ≤ 1/2。整数 a 从 −1010 取到 0（1/2 不是整数，取到 0 为止），个数 = 0−(−1010)+1 = 1011 个。

验算：a=0：|1|+|2020|=2021 ✓；a=−1010：|1+2020|+|0|=2021 ✓；a=1：|−1|+|2022|=2023 ✗；a=−1011：|2023|+|−2|=2025 ✗。

【另解 · 零点分段】两个零点：a=1/2（使 1−2a=0）、a=−1010（使 2a+2020=0）。

① 当 a ≥ 1/2：原式=(2a−1)+(2a+2020)=4a+2019，令它等于 2021 得 a=1/2，不是整数，舍去；

② 当 −1010 ≤ a < 1/2：原式=(1−2a)+(2a+2020)=2021，恒成立——这一整段里的整数全部适合；

③ 当 a < −1010：原式=(1−2a)+(−2a−2020)=−4a−2019，令它等于 2021 得 a=−1010，不在本段范围内，舍去。

综上：整数解为 −1010 ～ 0，共 1011 个（两种方法结果一致，互为印证）。

易错提醒：① 端点 a=−1010 千万别丢——此时 |2a+2020|=0，它是整数解；② 个数 = 大数 − 小数 + 1，别忘了“+1”；③ 考场上先用几何意义“看穿”答案，再用零点分段验算，双保险。

参考答案与解析第 4 题

第 4 题答案：A（最小值为 c）

4.答案：A。

【思路】“到三个点的距离和”模型：每个 |x−P| 都是 x 到定点 P 的距离。三个距离之和，当 x 站在中间那个点上时最小，最小值 = 最右点 − 最左点（与中间点具体在哪无关）。

第 1 步 · 找出三个定点（让每个绝对值内部等于 0 的 x 值）：

· |x−(a+b)/3| → 定点 P2=(a+b)/3；

· |x−(a+c)/2| → 定点 P3=(a+c)/2；

· |x+(c−a)/2|=|x−(a−c)/2| → 定点 P1=(a−c)/2。

第 2 步 · 给三个定点排序（利用 a<0<b<c）：

· P2−P1=(a+b)/3−(a−c)/2=(−a+2b+3c)/6>0（−a、2b、3c 全为正）→ P1 在 P2 左边；

· P3−P1=(a+c)/2−(a−c)/2=c>0 → P1 在 P3 左边；

· P3−P2=(a+c)/2−(a+b)/3=(a+3c−2b)/6>0（因 b<c，3c−2b>c>0）→ P2 在 P3 左边。

∴ 从左到右依次为 P1、P2、P3。

第 3 步 · 为什么 x 站在中间点 P2 处最小？当 x 夹在 P1、P3 之间时，|x−P1|+|x−P3|=P3−P1=c（定值），于是原式 = c + |x−P2| ≥ c，当且仅当 x=P2 时取等号；若 x 跑到 P1、P3 外侧，则 |x−P1|+|x−P3|>c，原式更大。

图 2　x 站在中间点 P2 处，三个距离之和最小；最小值 = P3−P1 = c

第 4 步 · 结论。最小值 = P3−P1=(a+c)/2−(a−c)/2=c，选 A。

选项陷阱：C 项 (a+9c−2b)/6 恰好是把 x 放在最右点 P3 上算出的值（= c + (P3−P2) 那一段），并不是最小值——“站在端点”是这类题最常见的失分点。特值检验：取 a=−1、b=2、c=3，三个定点为 −2、1/3、1，最小值 = 1−(−2) = 3 = c ✓；此时 B=5/3、C=11/3、D=8/3，全部排除。
模型推广：到奇数个定点距离和最小 → x 取正中间那个点；到偶数个定点 → x 取中间两点之间任意位置（如 4 个点 P1～P4 的最小值 = (P4−P1)+(P3−P2)）。“找中间点”的思想在以后学函数与方案选择时还会反复出现。
易错提醒：① 最小值只由最左、最右两个点决定，中间点只决定“x 站在哪”，不改变最小值大小；② |x+(c−a)/2| 的定点是 (a−c)/2（是负数），别误当成 (c−a)/2；③ 做题先把三个定点“钉”在数轴上排序，比硬算绝对值又快又稳。
