第 1 ~ 6 题
1

下列计算结果正确的是（　）

A(−x²y³)² = x⁴y⁶ B(3a²b²)² = 6a⁴b⁴ C(−x²)³ = −x⁵ D2m³ · 3m² = 5m⁵
A
破题钥匙
  • 积的乘方：每个因式分别乘方——(ab)ⁿ = aⁿbⁿ，系数也要乘方；
  • 幂的乘方：底数不变、指数相乘——(aᵐ)ⁿ = aᵐⁿ；
  • 单项式乘单项式：系数相乘（乘！不是加），同底数幂指数相加。
分步解析
A：(−x²y³)² = (−1)²·(x²)²·(y³)² = x⁴y⁶　✓（负数的偶次幂是正数）
B：3² = 9 ≠ 6，应为 9a⁴b⁴（系数要「平方」，不是「乘 2」）
C：指数 2×3 = 6，应为 −x⁶（幂的乘方指数相乘）
D：系数 2×3 = 6 ≠ 5，应为 6m⁵（系数相乘，不是相加）

B、C、D 恰好是三个「高频陷阱」：系数没平方、指数没相乘、系数拿去相加。

2

计算 (2/3)²⁰²⁵ · (−3/2)²⁰²⁶ 的结果是（　）

A2/3B−2/3C3/2D−3/2
C
破题钥匙
  • 偶次幂消负号：2026 是偶数 → (−3/2)²⁰²⁶ = (3/2)²⁰²⁶；
  • 底数 2/3 与 3/2 互为倒数，乘积为 1 —— 目标是「凑对子」；
  • 指数 2025 与 2026 差 1：拆出一个 (3/2)¹，剩下的配对。
分步解析
(2/3)²⁰²⁵ · (−3/2)²⁰²⁶ = (2/3)²⁰²⁵ · (3/2)²⁰²⁶
= (2/3)²⁰²⁵ · (3/2)²⁰²⁵ · (3/2)¹　← 把 2026 拆成 2025 + 1
= [(2/3)·(3/2)]²⁰²⁵ · (3/2)　← 逆用「积的乘方」把底数先乘
= 1²⁰²⁵ · (3/2) = 3/2
易错提醒

最容易错的是忘了负号的偶次幂，或者没注意到两个指数「差 1」而硬算到底。见到「底数互为倒数 + 指数差 1」，就按这个套路拆。

3

如果 A 是一个七次整式，B 也是一个七次整式，那么 A + B 一定是（　）

A十四次整式B七次整式 C不高于七次的整式D六次整式
C
破题钥匙
  • 整式相加只合并同类项，次数不会升高（升次是乘法干的事）；
  • 两个「最高次项」可能恰好抵消，次数因此下降。
分步解析

举两个「试验用」的例子就全明白了：

例 1：A = x⁷ + x，B = x⁷ − x → A + B = 2x⁷（还是七次）
例 2：A = x⁷ + 1，B = −x⁷ → A + B = 1（抵消成常数，次数降没了）

所以「一定」成立的只有：次数不超过七次 —— 选 C。

排除：A「十四次」——加法不升次；B「一定七次」——可能抵消；D「六次」——也可能恰好不抵消。

4

如果 m ≠ n，那么下列等式中正确的是（　）

A(m−n)² = −(m+n)² B(m−n)² = −(n−m)² C(m+n)(m−n) = (−m−n)(−m+n) D(−m−n)² = −(m−n)²
C
破题钥匙
  • 特值法最稳：取 m = 2、n = 1 代入逐个算，几秒钟锁定答案；
  • 代数理由：C 的两个括号同时添了负号——(−m−n) = −(m+n)、(−m+n) = −(m−n)，两个都变号，乘积不变。
分步解析

取 m = 2、n = 1：

A：左边 (2−1)² = 1，右边 −(2+1)² = −9　✗
B：左边 1，右边 −(1−2)² = −1　✗（平方永远非负，两边一正一负）
C：左边 3×1 = 3，右边 (−3)×(−1) = 3　✓
D：左边 (−3)² = 9，右边 −1　✗

C 的本质：(−m−n)(−m+n) = [−(m+n)]·[−(m−n)] = (m+n)(m−n)，两个因式「双双变号」时乘积不变号。

5

下列各式因式分解正确的是（　）

A2x + 2y = 2(x + y) Bx² − 5x + 6 = x(x − 5) + 6 Cx² + 2x − 3 = x(x + 2 − 3/x) Dx² + xy + ¼y² = (x + ½y)²
D
破题钥匙
  • 判断因式分解的两条合格标准：① 等号两边相等；② 右边是几个整式的乘积（不能露着加号、不能出现分式）；
  • 老师的阅卷口径再加一条：要「降次」——分解后因式的次数要低于原多项式（老师对 A 的批注就是「没有降次」）；
  • 「整式」允许分数系数——½y 是整式，别误以为系数必须是整数。
分步解析（逐项体检）
B：等号成立，但右边是「积 + 数」——加号露在外面，不是乘积形式 → ✗（假分解）
C：等号成立，但括号里出现 3/x，是分式不是整式 → ✗（分式因式）
D：验算右边 (x + ½y)² = x² + 2·x·(½y) + (½y)² = x² + xy + ¼y²，等号成立；右边是「整式 × 整式」，且原式 2 次 → 因式 1 次，降次了 → 正确，选 D ✓
A：右边 = 2·(x+y)，等号也成立、也是整式的积——但 没有降次（原式 1 次，分解后还是 1 次），按阅卷口径不算正确的因式分解 → ✗（老师批注：没有降次）

结论：选 D（与老师参考答案一致）。记牢这条阅卷口径：因式分解要「降次」。

易错提醒

① 常见误判：以为 D「系数是分数就不算因式分解」——错！整式允许分数系数。② 严谨说明：按课本定义「把多项式化为几个整式的积」，A 的等号其实也成立（2 与 x+y 都是整式）——但考试口径以「降次」为准，记住选 D。两条判断标准（相等 + 整式的积）仍是基本功，「降次」是本题的裁决线。

6

已知 p = −m − n，q = mn，那么关于 x 的整式 x² + px + q 因式分解的结果是（　）

A(x+m)(x+n)B(x−m)(x−n) C(x+m)(x−n)D(x−m)(x+n)
B
破题钥匙
  • 把 p、q 翻译回 m、n：p = −(m+n)，q = mn；
  • 十字相乘模型：x² − (m+n)x + mn = (x−m)(x−n)（两数之积 mn、之和 −(m+n)）。
分步解析
x² + px + q = x² − (m+n)x + mn
= (x − m)(x − n)　← (−m)·(−n) = mn，(−m)+(−n) = −(m+n)

验算：把右边展开 x² − nx − mx + mn = x² − (m+n)x + mn，与原式完全一致 → 选 B。

第 7 ~ 18 题
7

化简：3x²y − x²y − z⁴ − 2yx² + z⁴ = ______

0
破题钥匙
  • 合并同类项前先「认脸」：字母顺序不影响身份，2yx² 就是 2x²y；z⁴ 一正一负是一对。
分步解析
原式 = (3 − 1 − 2)x²y + (−1 + 1)z⁴ = 0·x²y + 0·z⁴ = 0
易错提醒

别把 −2yx² 当成「新面孔」漏掉；三块 x²y 合起来系数 3−1−2 = 0，两块 z⁴ 也互相抵消，所以整题结果是 0。

8

简便计算：19.8 × 20.2 = ______

399.96
破题钥匙
  • 两个数关于 20 对称（一个少 0.2、一个多 0.2）→ 平方差公式：(a−b)(a+b) = a² − b²。
分步解析
19.8 × 20.2 = (20 − 0.2)(20 + 0.2) = 20² − 0.2² = 400 − 0.04 = 399.96

0.2² = 0.04（不是 0.4！小数点要移两位）。

验算

399.96 ÷ 19.8 = 20.2 ✓（商恰为另一个因数）。

9

若 (a−2)x²yᵃ⁺³ 是关于 x、y 的六次单项式，则 a = ______

a = 1
破题钥匙
  • 单项式的次数 = 所有字母指数之和；
  • 别忘了检查系数 a − 2 ≠ 0（系数为 0 就不是单项式了）。
分步解析
2 + (a + 3) = 6　→　a + 5 = 6　→　a = 1

检查：a = 1 时系数 a − 2 = −1 ≠ 0 ✓，合格。

10

如果单项式 3a²ᵐ⁻⁴b⁶ 和 −4a²b⁴ⁿ 是同类项，那么 n − m 的值是 ______

−3/2
破题钥匙
  • 同类项 = 字母相同、相同字母的指数也相同（与系数无关）→ 列两个等式。
分步解析
2m − 4 = 2 → m = 3；　4n = 6 → n = 3/2
n − m = 3/2 − 3 = −3/2
11

计算：(¼x − ⅔x²y) · (−12xy) = ______

−3x²y + 8x³y²
破题钥匙
  • 分配律：单项式乘多项式，每项都乘到；
  • 盯紧符号：⅔x²y 乘负数 → 变正。
分步解析
¼x·(−12xy) = −3x²y
−⅔x²y·(−12xy) = +8x³y²　← ⅔×12 = 8，负负得正
原式 = −3x²y + 8x³y²
验算

系数：¼×(−12) = −3 ✓；⅔×12 = 8 ✓。字母：x·xy = x²y，x²y·xy = x³y² ✓。

12

计算：(7x⁴y⁵ − x²y³) ÷ x²y³ = ______

7x²y² − 1
破题钥匙
  • 多项式 ÷ 单项式 = 每一项分别除再相减；
  • 同底数幂相除指数相减：aᵐ ÷ aⁿ = aᵐ⁻ⁿ；相同的东西相除得 1，不是 0！
分步解析
7x⁴y⁵ ÷ x²y³ = 7x²y²
x²y³ ÷ x²y³ = 1　← 最大失分点！
原式 = 7x²y² − 1
13

因式分解：x² − 14x − 32 = ______

(x−16)(x+2)
破题钥匙
  • 十字相乘：找两个数，积 = −32，和 = −14；积是负 → 一正一负，和是负 → 负的那个绝对值大。
分步解析

把 −32 拆成「一正一负、负大正小、和为 −14」：

(−16) × 2 = −32，(−16) + 2 = −14 ✓
x² − 14x − 32 = (x − 16)(x + 2)
验算

(x−16)(x+2) = x² + 2x − 16x − 32 = x² − 14x − 32 ✓。

14

因式分解：x(a−b)² − y(b−a)³ = ______

(a−b)²(x+ay−by)
破题钥匙
  • 先统一底数：b − a = −(a − b)，而 (b−a)³ = −(a−b)³（奇次幂要变号）；
  • 两项都有了公因式 (a−b)²，提出来。
分步解析
原式 = x(a−b)² − y·[−(a−b)³] = x(a−b)² + y(a−b)³
= (a−b)²·[x + y(a−b)] = (a−b)²(x + ay − by)

也可写成 (a−b)²[x + (a−b)y]，都对。

验算

取 a = 2、b = 1：原式 = 2×1 − 1×(−1) = 3；分解式 = 1×(2+2−1) = 3 ✓。

15

如果整式 4x² − mx + 25 是一个整式的平方，那么 m 的值是 ______

±20
破题钥匙
  • 4x² = (2x)²、25 = 5² —— 首尾都是现成的平方，中间项 ±2·(2x)·5 = ±20x；
  • 完全平方有两个方向：(2x+5)² 和 (2x−5)²，别只答一个！
分步解析
(2x + 5)² = 4x² + 20x + 25 → −m = 20 → m = −20
(2x − 5)² = 4x² − 20x + 25 → −m = −20 → m = 20
∴ m = ±20
易错提醒

「±」漏一半是本题最大失分点——题目只说「是某整式的平方」，加号减号都符合。

16

计算（结果用幂的形式表示）：(x+y) · 2[(y+x)²]² + 3(−x−y)⁵ = ______

−(x+y)⁵
破题钥匙
  • 把 (x+y) 当成一个「大字母」整体处理（换元思想，不用真换）；
  • 指数层层相乘再相加：[(y+x)²]² = (x+y)^(2×2) = (x+y)⁴，再乘前面的 (x+y)¹，总次数 1+4 = 5；
  • (−x−y) = −(x+y)：5 是奇次幂，负号提到外面：3(−x−y)⁵ = −3(x+y)⁵；
  • 两项都含 (x+y)⁵ → 系数直接相减：2 − 3 = −1。
分步解析
(x+y)·2[(y+x)²]² = 2·(x+y)·(x+y)^(2×2) = 2(x+y)⁵
3(−x−y)⁵ = 3·[−(x+y)]⁵ = −3(x+y)⁵
原式 = 2(x+y)⁵ − 3(x+y)⁵ = −(x+y)⁵

「结果用幂的形式表示」正是提示：最后能合成一个幂。若算出两项指数不同（如 (x+y)⁷ 与 (x+y)⁵），说明中途指数算错了——回头检查中括号外层的指数。

易错提醒

本题最大的坑是指数层级：[(y+x)²]² 的总次数是 2×2 = 4（不是 2+2）；外层的 2 和内层的 2 都要发挥作用，加上前面 (x+y) 本身的 1 次，共 5 次。另一个坑：(−x−y)⁵ 的负号——奇次幂要把负号提出来。

17

已知 (x+1)ˣ⁺⁶ = 1，x 的值是 ______

0、−2、−6
破题钥匙
  • 「幂等于 1」的三种来源：① 底数 = 1；② 底数 ≠ 0 且指数 = 0；③ 底数 = −1 且指数是偶数。
分步解析
① x + 1 = 1 → x = 0　（1⁶ = 1 ✓）
② x + 6 = 0 且 x + 1 ≠ 0 → x = −6　（(−5)⁰ = 1 ✓）
③ x + 1 = −1 → x = −2，此时指数 x + 6 = 4 是偶数 → (−1)⁴ = 1 ✓　x = −2

三种情况都检查到，一个不漏。

易错提醒

绝大多数同学只想到「指数为 0」，漏掉 −1 的偶次幂（情况③）——这恰是命题人埋的采分点。

（贾宪三角 / 开方作法本源图）按照它的构造规则可知：从左边数第 3 条斜线的第 m 个数是 ______（用含 m 的代数式表示）

m(m+1)/2
破题钥匙
  • 先写出来再看：第 3 条斜线上的数依次是 1, 3, 6, 10, 15, 21, …（图中汉字「三、六、十、十五」正好印证）；
  • 看增量：+2, +3, +4, +5, …（依次多 1）→ 这是「三角形数」：第 m 个数 = 1+2+3+…+m。
分步解析

「从左边数」：第 1 条斜线全是 1；第 2 条是 1, 2, 3, 4, …；第 3 条从第 3 行开始，取每行左起第 3 个：

第 3 条斜线：1，3，6，10，15，21，…
增量：　　+2，+3，+4，+5，…（每次多加 1）
第 m 个数 = 1 + 2 + 3 + … + m = m(m+1)/2

等差数列求和（首尾配对）：1+m = 2+(m−1) = … 共 m/2 对 → 和 = m(m+1)/2。

验算

m=2 → 3（图中「三」）✓；m=3 → 6（「六」）✓；m=4 → 10（「十」）✓；m=5 → 15（「十五」）✓。

杨辉三角（贾宪三角）：金色为第 3 条斜线 1, 3, 6, 10, 15, 21, …

3ax⁵ · 6bx⁷ = 3×6 · a · b · x⁵ · x⁷　……（　　）

= 18abx¹²

归纳：单项式与单项式相乘，把它们的 ______、______ 分别相乘。

见解析
分步解析

第一空：因数位置换了（a、b、x⁵ 挪到一起）→ 乘法交换律

20

关于 x 的整式 x²+3x−a 与 x²+bx 相乘的积不含二次项和三次项，求 a 与 b 的值。

a=−9, b=−3
破题钥匙
  • 「不含某次项」翻译成：展开后该项系数 = 0；
  • 先展开、再对照系数。只需盯住三次项和二次项。
分步解析
(x²+3x−a)(x²+bx) = x⁴ + bx³ + 3x³ + 3bx² − ax² − abx
= x⁴ + (b+3)x³ + (3b−a)x² − abx
三次项系数：b + 3 = 0 → b = −3
二次项系数：3b − a = 0 → a = 3b = −9
验算

代回：积 = x⁴ − (−9)(−3)x = x⁴ − 27x，只有四次项和一次项 ✓。

21

因式分解：x²y² − x² − y² + 1

(x+1)(x−1)(y+1)(y−1)
破题钥匙
  • 四项式 → 两两分组提公因式；
  • 分组后出现 (y²−1)，再用平方差连续拆到底。
分步解析
原式 = (x²y² − x²) − (y² − 1)　← 前两项有 x²，后两项凑 (y²−1)
= x²(y² − 1) − (y² − 1)
= (y² − 1)(x² − 1)　← 整体提公因式 (y²−1)
= (y+1)(y−1)(x+1)(x−1)
验算

取 x=2、y=3：原式 = 36 − 4 − 9 + 1 = 24；分解式 = 4×2×3×1 = 24 ✓。

易错提醒

提公因式 (y²−1) 时，第二项前面是减号，(y²−1) 提走后剩 1 不是剩 0：−(y²−1) = −1·(y²−1)。

22

已知 a(a+1−c) − a(a−c) − b = 4，求 (a²+b²)/2 − ab 的值。

8
破题钥匙
  • 条件别急着用——先展开化简，看它到底给了什么；
  • 目标式是 a²、b²、ab 的组合 → 配方成 (a−b)² 的马甲。
分步解析

第一步：化简条件

a(a+1−c) − a(a−c) − b = (a² + a − ac) − (a² − ac) − b = a − b
∴ a − b = 4

第二步：改写目标（配方）

(a² + b²)/2 − ab = (a² − 2ab + b²)/2 = (a − b)²/2

第三步：代入

= 4²/2 = 8
易错提醒

别试图分别求 a、b —— 条件只有一个，求不出两个未知数；这类题的出路永远是「整体代换」。

小明的因式分解过程如下，他做得正确吗？如果不正确，是从第几步出的错？请写出正确的因式分解过程。

16 − a² + 4ab − 4b² = (16 − a²) + (4ab − 4b²)　……①
= (4+a)(4−a) + 4b(a−b)　……②
= 4b(1+a)(1−a)(a−b)　……③
第①步出错
破题钥匙
  • 分组分解法的成败手筋：分组后各组能分解，且两组之间要有公因式；
  • 体检小明的分组：第①步分了 (16−a²) 和 (4ab−4b²) 两组，第②步各自分解为 (4+a)(4−a)、4b(a−b)——组内都没错，但两组之间没有任何公因式，往下走必然是死路；
  • 所以错误的根源在第①步：分组不当（老师答案）。第③步「硬提 4b」只是死路的必然结果——两个没有公因式的式子相加，硬凑出 4b(1+a)(1−a)(a−b)，等号根本不成立。
分步解析

结论：不正确，从第①步（分组）就出了错（与老师参考答案一致）。

为什么分组错了？按小明的分法，(16−a²) 分解为 (4+a)(4−a)，(4ab−4b²) 分解为 4b(a−b)，两组之间没有公因式，无法继续分解——这样的分组从一开始就注定失败，第③步把两个没有公因式的式子硬凑成 4b(1+a)(1−a)(a−b)，等号已经不成立。

正确解法：换一种分组——把后三项放一起，正好是完全平方：

16 − a² + 4ab − 4b² = 16 − (a² − 4ab + 4b²)
= 4² − (a − 2b)²　← 括号内配方：a² − 4ab + (2b)²
= [4 + (a − 2b)][4 − (a − 2b)] = (4 + a − 2b)(4 − a + 2b)

去括号时注意符号：4 − (a−2b) = 4 − a + 2b。与老师参考答案一致。

验算

取 a=1、b=1：原式 = 16−1+4−4 = 15；分解式 = (4+1−2)(4−1+2) = 3×5 = 15 ✓。

易错提醒

严谨地说：第①、②步的等号本身都还成立（分组、组内分解都没算错数），第③步的等号才真正不成立——所以「错在第几步」有两种说法：按「等式何时失效」是第③步；按「错误根源／分组策略」（老师的阅卷口径）是第①步。考试作答以老师口径为准：第①步分组不当。两种说法都指向同一个正确分组：16 − (a² − 4ab + 4b²)。

先因式分解，再求值：(x−1)² + (2x+1)(x−1) + 3x² − 3，其中 x = −0.5。

0
破题钥匙
  • 3x² − 3 = 3(x²−1) = 3(x−1)(x+1)——三项都藏着 (x−1)！
  • 眼尖的话：x = −0.5 → 2x+1 = 0，答案可能「秒出」。
分步解析
原式 = (x−1)² + (2x+1)(x−1) + 3(x−1)(x+1)
= (x−1)·[(x−1) + (2x+1) + 3(x+1)]　← 三项都有 (x−1)，提！
= (x−1)(x−1+2x+1+3x+3) = (x−1)(6x+3)
= 3(x−1)(2x+1)

求值：x = −0.5 → 2x+1 = 0

原式 = 3×(−1.5)×0 = 0
易错提醒

「先因式分解再求值」是题目的程序要求，直接硬展开代入即使结果对也会被扣过程分。

已知 x² − 3x + 1 = 0，求 x³ + 5x² − 23x + 2025 的值。（阅读材料给出了两种「降次代入」的方法示范）

2017
破题钥匙
  • 核心思想（材料的精髓）：不求 x，用条件「降次」——x² = 3x − 1，凡见到 x² 就替换；
  • x³ 也能降：x³ = x·x² = x(3x−1)，再把里面的 x² 换掉，一路降到「一次」。
分步解析（法一：逐层降次）

第一步：先把 x³ 降到一次

x³ = x·x² = x(3x − 1) = 3x² − x = 3(3x−1) − x = 8x − 3

第二步：整体代入（x² → 3x−1，x³ → 8x−3）

原式 = (8x − 3) + 5(3x − 1) − 23x + 2025
= 8x − 3 + 15x − 5 − 23x + 2025
= 0·x + 2017 = 2017

妙处：所有含 x 的项全部抵消，只剩常数——说明「不求 x」是完全正确的路线。

法二（整体凑形，更漂亮）：由条件 x² − 3x = −1，把原式朝 (x²−3x) 的倍数凑：

原式 = (x³ − 3x²) + (8x² − 24x) + x + 2025
= x(x²−3x) + 8(x²−3x) + x + 2025 = −x − 8 + x + 2025 = 2017

已知 2a² + 8a + 4b² − 12b + 17 = 0，求 −½a²b 的值。

−3
破题钥匙
  • 一个等式、两个未知数 → 大概率是「平方和 = 0」的配方题；
  • 目标：把条件配成 p·( )² + q·( )² = 0，用「非负数之和为零 → 每个都为零」。
分步解析
2a² + 8a + 4b² − 12b + 17 = 0

配方（8a = 2×2×2 → 补 2²；12b = 2×4×(3/2) → 补 (3/2)²）：

2(a² + 4a + 4) + 4(b² − 3b + 9/4) + 17 − 8 − 9 = 0
2(a+2)² + 4(b − 3/2)² = 0

两个非负数之和为 0 → 每个 = 0：

a + 2 = 0 → a = −2；　b − 3/2 = 0 → b = 3/2

求值：

−½a²b = −½ × (−2)² × 3/2 = −½ × 4 × 3/2 = −3
验算

代回条件：2×4 + 8×(−2) + 4×2.25 − 12×1.5 + 17 = 8 − 16 + 9 − 18 + 17 = 0 ✓。

线段 BC 长度为 a，在线段 BC 上截取线段 CJ = b，再延长 BC 至 M，使 CM = b（a > b > 0），分别作正方形 ABCD、正方形 BMFN 和正方形 PBJO。

(1) 分别计算图中长方形 PBMQ 和阴影部分图形的面积，可以发现一个乘法公式 ______；

(2) 已知正方形 BMFN、正方形 PBJO 的面积分别是 7 和 3，计算长方形 KJME 的面积；

(3) 分别联结 AG、AJ、QG、QJ，已知正方形 BMFN 的面积是 S₁、正方形 KOHD 的面积是 S₂，用含 S₁、S₂ 的代数式表示四边形 AJQG 的面积。

见下
破题钥匙（先把每个点翻译成边长）
  • 底边从左到右是 B、J、C、M：BJ = a−b，JC = b，CM = b，BM = a+b；
  • 三个正方形边长：ABCD = a（以 BC 为边）、BMFN = a+b（以 BM 为边）、PBJO = a−b（以 BJ 为边）；
  • 看图确认：P、O、H、Q 同高（高 a−b）；A、K、D、E 同高（高 a）；N、I、G、F 在顶边。小正方形 KOHD 的边长恰为 b（右上角空白块）。
图 2 结构（示意取 a = 5、b = 2）：金色阴影 = 正方形 ABCD 挖去右上角小正方形 KOHD；虚线框为长方形 PBMQ
分步解析 · 第(1)问

① 长方形 PBMQ 的面积：长 = BM = a+b，宽 = PB = a−b：

S(PBMQ) = (a+b)(a−b)

② 阴影部分的面积：看图，阴影 = 正方形 ABCD 挖去右上角的小正方形 KOHD（边长 b）：

S(阴影) = a² − b²

③ 为什么两者相等？把阴影里「PBJO 正上方的小竖条」（宽 a−b、高 b）剪下来转 90°，正好补进 PBMQ 右边缺的窄条（宽 b、高 a−b）——两块面积一样，形状能互相拼成！所以：

(a + b)(a − b) = a² − b²　（平方差公式）
验算

取 a=5、b=2：(5+2)(5−2) = 21；5² − 2² = 25 − 4 = 21 ✓。

第(2)问：蓝色虚线框 = 长方形 KJME（宽 JM = 2b，高 JK = a）
分步解析 · 第(2)问

① KJME 的面积（用 a、b 表示）：宽 JM = JC + CM = 2b，高 JK = a（K 与 A 同高）：

S(KJME) = 2b · a = 2ab

② 翻译条件：S(BMFN) = (a+b)² = 7，S(PBJO) = (a−b)² = 3

③ 两式相减（正好用上第(1)问的平方差思想）：(a+b)² − (a−b)² = 4ab：

4ab = 7 − 3 = 4　→　ab = 1

④ 回代：

S(KJME) = 2ab = 2 × 1 = 2
验算

a+b = √7 ≈ 2.6458，a−b = √3 ≈ 1.7321 → a ≈ 2.1889、b ≈ 0.4568 → ab ≈ 1.0000 ✓，2ab ≈ 2 ✓。

第(3)问：红色四边形 AJQG 的四个顶点分别落在大正方形 BMFN 的四条边上，四角三角形即「要减去的部分」
分步解析 · 第(3)问（补形法）

① 关键观察：联结后，四边形 AJQG 的四个顶点正好「踩」在大正方形 BMFN 的四条边上（A 在左边、J 在下边、Q 在右边、G 在上边）。于是：

S(AJQG) = S(BMFN) − S(△ABJ) − S(△JMQ) − S(△QFG) − S(△GNA)

② 四个角三角形都是直角三角形，两条直角边直接从图上读：

三角形两条直角边面积
左下 △ABJAB = a，BJ = a−b½a(a−b)
右下 △JMQJM = 2b，MQ = a−bb(a−b)
右上 △QFGQF = 2b，FG = bb² = S₂
左上 △GNAGN = a，NA = b½ab

③ 列式化简（其中 S₁ = (a+b)²，S₂ = b²）：

S(AJQG) = S₁ − ½a(a−b) − b(a−b) − S₂ − ½ab
四个三角形合计 = ½a² − ½ab + ab − b² + b² + ½ab = ½a² + ab
S(AJQG) = (a+b)² − ½a² − ab = ½a² + ab + b²

④ 凑成 S₁、S₂ 的组合（朝平方的方向配）：

½a² + ab + b² = ½(a² + 2ab + b²) + ½b² = ½S₁ + ½S₂
∴ S(AJQG) = (S₁ + S₂) / 2
验算

取 a=5、b=2：S₁ = 49、S₂ = 4 → (S₁+S₂)/2 = 26.5；直接算四角三角形 7.5 + 6 + 4 + 5 = 22.5，49 − 22.5 = 26.5 ✓。

易错提醒

① 别把 KJME 的高当成 a−b——K 与 A 同高（都在高度 a 处），高是 a；② 第(3)问化简时右上角三角形 QFG 的面积恰好等于 S₂（QF = 2b、FG = b，½×2b×b = b²），这是个可以「白捡」的观察；③ 最后一步要主动「凑」，把 ½a²+ab+b² 写成 ½(a²+2ab+b²)+½b²，题目要求的结果就自己浮出来了。

阅读材料：如果当 x = a 时，一个整式的值等于 0，那么 (x−a) 就一定是这个整式的一个因式；反过来，如果 (x−a) 是整式的一个因式，那么当 x = a 时，这个整式的值一定等于 0。

已知整式 P = x⁴ − x³ − 7x² + 5x + 10：

(1) 请判断 (x+1) 是否是整式 P 的一个因式；

(2) 当整式 P 的一次项系数变为 k 时，(x+1) 仍是它的一个因式，求 k 的值；

(3) 请尝试将整式 P 进行因式分解。

见下
破题钥匙
  • 材料的核心（因式定理的七年级版）：「代入 x = a 看值是否为 0」⇔「(x−a) 是不是因式」；
  • 判断 (x+1)：注意它对应 x = −1（令 x+1 = 0）；
  • 第(3)问找因式：试 10 的因数 ±1、±2、±5、±10（常数项的因数是首选嫌疑人）。
分步解析 · 第(1)问

(x+1) 对应 x = −1，把 x = −1 代入 P：

P(−1) = (−1)⁴ − (−1)³ − 7·(−1)² + 5·(−1) + 10 = 1 + 1 − 7 − 5 + 10 = 0
∴ (x+1) 是 整式 P 的一个因式 ✓
分步解析 · 第(2)问

一次项系数变为 k：P′ = x⁴ − x³ − 7x² + kx + 10。(x+1) 仍是因式 → x = −1 时 P′ = 0：

P′(−1) = 1 + 1 − 7 − k + 10 = 5 − k = 0　→　k = 5

代回验证：k = 5 时 P′ 就是原来的 P，而 P(−1) = 0 ✓，自洽。

分步解析 · 第(3)问

第一步：用材料的方法「抓嫌疑人」——试常数项 10 的因数：

x = 1：1 − 1 − 7 + 5 + 10 = 8 ≠ 0　✗
x = 2：16 − 8 − 28 + 10 + 10 = 0　✓ → (x−2) 也是因式！

第二步：拆项分组，一次到位（把 −7x² 拆成 −2x² − 5x²，前后各配出一个 (x²−x−2)）：

P = x⁴ − x³ − 2x² − 5x² + 5x + 10
= x²(x² − x − 2) − 5(x² − x − 2)
= (x² − x − 2)(x² − 5)
= (x + 1)(x − 2)(x² − 5)

其中 x² − x − 2 = (x+1)(x−2)（十字相乘：1×(−2) = −2，1+(−2) = −1 ✓）。x² − 5 在七年级有理数范围内不能再分解。

另一条路（用材料方法连贯做）：已知 (x+1)、(x−2) 是因式，可设 P = (x+1)(x−2)(x²+px+q)，对照系数解出 p = 0、q = −5，结果相同。

验算

(x+1)(x−2) = x² − x − 2；(x²−x−2)(x²−5) = x⁴ − x³ − 2x² − 5x² + 5x + 10 = x⁴ − x³ − 7x² + 5x + 10 ✓ 与 P 完全一致。

易错提醒

① 判断 (x+1) 时代入的是 x = −1（令括号 = 0 解出），别代成 x = 1；② 试根别从大数试起——常数项的因数从小往大试；③ 最后一步若答 (x²−5) 还能拆成 (x+√5)(x−√5)，注意七年级还没学无理数，在有理数范围内分解到 (x²−5) 为止。
