反比例函数与图像

y = k/x（k ≠ 0）—— 从"积不变"出发，用描点法认识双曲线。

一什么是反比例函数

y = k/x  （k ≠ 0）  ⇔  x · y = k

两个变量 x 和 y，只要它们的乘积恒等于一个不为 0 的常数 k，y 就叫做 x 的反比例函数。记住这句话：积不变，就是反比例。

生活里到处都是"积不变"：

场景不变的积关系式
长方形面积固定为 12长 × 宽 = 12y = 12/x
总路程 60 km 走完速度 × 时间 = 60v = 60/t
30 颗糖分给 x 个人人数 × 每人颗数 = 30y = 30/x
全班 45 人分组组数 × 每组人数 = 45y = 45/x

注意：x = 0 时无意义（分母不能为 0），所以图像永远不会碰到 y 轴。

二描点法画 y = 6/x

先列表取点（正负各取几个，x 越大 y 越小）：当 x = 6 时 y = 1，x = 1 时 y = 6……

x…−12−6−3−2−1123612…
y = 6/x…−0.5−1−2−3−663210.5…

每一个乘积都是 6：1×6、2×3、3×2、6×1……（−1）×（−6）= 6 也成立！

三k > 0：图像在一、三象限

y = 6/x y = 3/x y = 1/x

三条曲线形状相同，只是"胖瘦"不同：|k| 越大，曲线离原点越远。

四k < 0：图像在二、四象限

y = −6/x y = −3/x y = −1/x

和 k > 0 的图像对比：正好是绕原点旋转 180° 的样子。

五五大性质（背下来）

k 的符号图像位置在每个象限内的增减性
k > 0一、三象限y 随 x 增大而减小
k < 0二、四象限y 随 x 增大而增大
① 两支永不分离双曲线有两支，分别位于两个象限。
② 贴近两轴永不相交x 越大曲线越贴近 x 轴（y→0），x 越接近 0 越贴近 y 轴，但永远碰不到。
③ 关于原点对称把图像绕原点旋转 180°，自己和自己重合。
④ |k| 决定"胖瘦"|k| 越大离原点越远；过 (1, k) 点可快速定位。

六动手试：拖动 k，再拖曲线上的点

k =6 （k ≠ 0，滑到 0 附近会自动跳过）

在图上按住拖动：无论点拖到哪里，x × y 永远等于 k。

七易错点提醒

⚠ 考试最容易在这里丢分：
  • 增减性必须限定"在每个象限内"。反例：y = 6/x 中，x 从 −1 变到 1，y 从 −6 变到 6——x 变大，y 也变大了！跨象限不能直接比较。
  • x = 0 无意义，写解析式或取值范围时别忘 k ≠ 0、x ≠ 0。
  • 判断是不是反比例函数，看 xy 是否恒等于同一个非零常数。y = 6/x、xy = 6、y = 6x⁻¹ 是同一个函数的三种写法。
  • "k 越大离原点越远"应该说 |k|：k = −6 的图像比 k = 1 的离原点远（|−6| > |1|）。
  • 双曲线不是一条直线弯过来的，两支是分开的——画图时别用一条线硬连过去。
