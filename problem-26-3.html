第 26 题（3）示意图：△MNO 为等腰直角三角形，∠NMO = 90°

抛物线 y = −x² + 2x + 3（过 A(−1, 0)、B(3, 0)、C(0, 3)，对称轴 x = 1，顶点 (1, 4)）。M 在对称轴上，N 在抛物线上，且 MN = MO、MN ⊥ MO —— 满足条件的 N 共有 4 个，恰好分布在四个象限。

情况点 M（在对称轴 x = 1 上）点 N（在抛物线上）代回抛物线所得方程
① 第一象限M₁ (1, (√21 − 1)/2) ≈ (1, 1.79)N₁ ((1 + √21)/2, (√21 − 3)/2) ≈ (2.79, 0.79)m² + m − 5 = 0
② 第三象限M₂ (1, −(√21 + 1)/2) ≈ (1, −2.79)N₂ ((1 − √21)/2, −(√21 + 3)/2) ≈ (−1.79, −3.79)m² + m − 5 = 0
③ 第二象限上文已证明M₃ (1, (√13 − 1)/2) ≈ (1, 1.30)N₃ ((3 − √13)/2, (√13 + 1)/2) ≈ (−0.30, 2.30)m² + m − 3 = 0
④ 第四象限M₄ (1, −(√13 + 1)/2) ≈ (1, −2.30)N₄ ((3 + √13)/2, (1 − √13)/2) ≈ (3.30, −1.30)m² + m − 3 = 0
  1. ∠NMO 是直角 ⇒ 直角边是 MN 与 MO（NO 是斜边），必须同时满足 MN = MO 且 MN ⊥ MO。图中 M 处的小方形是直角记号，MN、MO 中点处的单短线记号表示这两条直角边相等。
  2. 「横竖互换」找 N：M(1, m) 到 O 是「横 1、竖 m」（按长度说），横竖互换后 M→N 只可能是 (m, −1) 或 (−m, 1)——这两种与 M→O 垂直；另外两种组合 (−m, −1)、(m, 1) 不垂直，舍去。单独查看某种情况时，图中虚线展示的正是这组「互换」。
  3. 把 N(1+m, m−1) 与 N(1−m, m+1) 分别代回 y = −x² + 2x + 3，得 m² + m − 5 = 0 与 m² + m − 3 = 0，各两个根，所以共 4 个 N 点。点击上方按钮或表格行可切换查看。
