一、填空题（第 1–14 题）

考点：整式的概念 · 幂的运算 · 乘法公式 · 因式分解 · 拼图面积

1概念答案：2
整式 2x²−3x−7 的二次项系数为 ＿＿＿.
钥匙“二次项”= x 的次数恰好为 2 的项，即 2x²；系数就是它前面的数字因数 2（要带符号）。
易错−3 是一次项的系数，−7 是常数项。数次数只数 x 的指数，跟系数大小无关。
2概念答案：x³−4x²+5x−6
将整式 x³+5x−6−4x² 按 x 降幂排列得 ＿＿＿.
钥匙降幂排列 = 按 x 的指数从大到小重新排队，每一项带着自己的符号一起搬家。
步骤
1给每项标"次"：x³（3 次）→ 4x²（2 次）→ 5x（1 次）→ −6（0 次）。
2从高到低排队：x³−4x²+5x−6。
易错−6 的负号是它自带的，别把它写成 +6；降幂只看 x 的指数，不看系数。
3同类项答案：3
若 12x²yz 与 −13xayzb 的和是单项式，则 a+b 的值为 ＿＿＿.
钥匙“和是单项式”→ 两式合并成了一项 → 它们是同类项：字母相同，且相同字母的指数相同。系数一正一负不妨碍它们是同类项。
步骤
1对照 x 的指数：a = 2。
2对照 z 的指数：b = 1（z¹ 的指数 1 通常省略不写）。
3a + b = 2 + 1 = 3。
验算合并系数：12 − 13 = 16 ≠ 0，和 = 16x²yz，确实是单项式 ✓
4整式加减答案：4x²−8x−3
已知：A = 3x²−5x+2，B = x²−3x−5，则 A+B = ＿＿＿.
钥匙合并同类项口诀：系数相加，字母指数不变。同号直接加，异号相减取大绝对值的符号。
步骤
1x² 项：3x² + x² = 4x²。
2x 项：−5x + (−3x) = −8x。
3常数项：2 + (−5) = −3。
验算取 x=1：A = 3−5+2 = 0，B = 1−3−5 = −7，A+B = −7；而 4−8−3 = −7 ✓
5幂运算答案：6a+a¹⁰
计算：a+2a+3a+a·a²·a³·a⁴ = ＿＿＿.
钥匙口诀：加法系数加，乘法指数加。两件事分开做，别混。
步骤
1加法（合并同类项）：a+2a+3a = (1+2+3)a = 6a。
2乘法（同底数幂相乘）：a·a²·a³·a⁴ = a1+2+3+4 = a¹⁰。
36a 与 a¹⁰ 不是同类项，只能写和：6a+a¹⁰。
易错a+2a = 3a，不是 a³！相加时指数不动，只有相乘时指数才相加。
6幂运算答案：−16
计算：4¹⁷ × (−14)15 = ＿＿＿.
钥匙两步走：① 负号看指数奇偶——口诀“奇负偶正”，15 是奇数 → 结果带负号；② 底数 4 与 14 是"倒数底数"，乘起来就是指数相减。
步骤
1(−14)¹⁵ = −(14)¹⁵ = −14¹⁵（15 个负因数相乘，负号留下）。
24¹⁷ × (−14¹⁵) = −4¹⁷4¹⁵ = −417−15 = −4² = −16。
验算小数字试规律：4³ × (−14)¹ = −4² = −16 ✓（指数 3−1=2）。
7多项式乘法 ★头号陷阱答案：x³−2x²y+2xy²−y³
计算：(x−y)(x²−xy+y²) = ＿＿＿.
陷阱警报它长得特别像立方差公式 (x−y)(x²+xy+y²) = x³−y³——但第二因式中间那项是 −xy！公式条件不满足，不能套。套了直接得 x³−y³，掉坑。
钥匙公式不匹配时，回到基本功：多项式乘多项式，逐项分配，一个不漏。第一因式的 x 和 −y，分别乘进第二因式的每一项。
步骤
1x 乘进去：x·x² = x³；x·(−xy) = −x²y；x·y² = +xy²。
2−y 乘进去：(−y)·x² = −x²y；(−y)·(−xy) = +xy²；(−y)·y² = −y³。
3合并同类项：−x²y−x²y = −2x²y；xy²+xy² = +2xy²。
4x³ − 2x²y + 2xy² − y³。
验算取 x=2，y=1：左边 (2−1)(4−2+1) = 1×3 = 3；右边 8−8+4−1 = 3 ✓。若错答 x³−y³ = 7 ≠ 3，立刻露馅。
8待定系数答案：3
若 (2x²+3x−1) 与关于 x 的二项式 ax+b 的积不含一次项，则 ab = ＿＿＿.
钥匙“不含一次项”= 展开后 x¹ 的系数为 0。先找出一次项由哪些乘积贡献，再令它等于零。
步骤
1一次项只来自两种搭配：3x·b 和 (−1)·ax，即 (3b−a)x。
2令 3b − a = 0 → a = 3b。
3ab = 3bb = 3（b≠0，否则二项式退化）。
易错x²·bx = 2bx³、x²·ax = 2ax³ 是三次项；(−1)·b 是常数——别把它们算进一次项。
9平方差答案：64
计算：987² − 995×979 = ＿＿＿.
钥匙硬算必死。找"对称轴"：995 和 979 都在 987 旁边——995 = 987+8，979 = 987−8。平方差公式反过来用。
步骤
1995×979 = (987+8)(987−8) = 987² − 8² = 987² − 64。
2原式 = 987² − (987² − 64) = 64。
验算取小数同型：17² − 19×15 = 289 − 285 = 4 = 2² ✓（19=17+2、15=17−2）。
10完全平方式答案：4 或 −6
x²−2(m+1)x+25 如果是完全平方式，那么常数 m 的值是 ＿＿＿.
钥匙完全平方式口诀：首平方，尾平方，积的两倍在中央，中间符号两分支。这里是 (x±5)² 的形状。
步骤
125 = 5²，所以完全平方式是 (x+5)² 或 (x−5)²。
2中间项：−2(m+1)x 必须等于 +10x 或 −10x。
3−2(m+1) = 10 → m+1 = −5 → m = −6；−2(m+1) = −10 → m+1 = 5 → m = 4。
易错只答一个就丢一半分——中间项可正可负，两解都要。
11单式除法答案：a³c/2
计算：a⁴bc ÷ 2ab = ＿＿＿.
钥匙单项式除以单项式：系数相除，同底数幂指数相减，只在被除式里出现的字母保留。
步骤
1系数：1 ÷ 2 = 12。
2a：a⁴÷a = a³；b：b÷b = 1（消掉）。
3c 只在前面有，照抄：a³c2。
易错① 忘掉系数 ½，答成 a³c；② 把 c 也"除没了"——除式里没有 c，c 原样保留。
12提公因式答案：a5n−5−1
若 n 为大于 1 的正整数，将 a5n−a⁵ 提取公因式后，则剩余的因式是 ＿＿＿.
钥匙公因式取各项都含的最低次幂：5n 与 5 谁小？n>1 → 5n > 5，最低次是 a⁵。
步骤
1a5n−a⁵ = a⁵(a5n−5−1)（指数相减：5n−5、5−5=0）。
2剩余因式：a5n−5−1。
易错a⁵ 提出 后变成 a⁰=1，别写成 0；剩余因式是"提取后括号里的整体"。
13系数对照答案：30
若 x²+mx+n 可因式分解为 (x+5)(x+1)，则 mn = ＿＿＿.
钥匙把 (x+5)(x+1) 展开成 x²+mx+n 的形状，再"对号入座"。
步骤
1(x+5)(x+1) = x²+x+5x+5 = x²+6x+5。
2对照：m = 6，n = 5。
3mn = 6×5 = 30。
易错x 项系数 = 5+1（两常数之和），常数项 = 5×1（两常数之积）——别对调。
14拼图 · 面积法 ★本卷必会答案：(m−n)² = (m+n)² − 4mn
如图①是一个长为 2m、宽为 2n 的长方形，沿图中虚线用剪刀均分成四个小长方形，再按图②的方式拼成一个正方形，请用两种不同的方法表示阴影部分的面积.
钥匙"两种方法"= 一条恒等式的两个视角：外面看用大减小，里面看直接量阴影边长。
步骤
1方法一（大正方形 − 四个长方形）：大正方形边长 = m+n，面积 (m+n)²；四个小长方形共 4mn。阴影 = (m+n)² − 4mn。
2方法二（直接量）：阴影小正方形边长 = m−n（上边 m 段与 n 段之差），面积 = (m−n)²。
3两法同源：(m−n)² = (m+n)² − 4mn。
易错图②上边两段是 m 和 n，所以边长是 m+n；中心空隙的边长是水平的 m 减 n（m>n 时），别答成 n−m。
验算取 m=5，n=3：(5−3)² = 4；(5+3)² − 4×15 = 64−60 = 4 ✓

二、选择题（第 15–18 题）

考点：整式次数 · 乘法公式辨析 · 因式分解的方向性 · 待定系数

15整式的次数答案：B
若 A、B 都是关于 x 的整式，且 A·B 是一个九次式，A+B 是一个五次式，则 A−B 的次数……（　）
A. 一定是 9　　B. 一定是 5　　C. 一定是 4　　D. 无法确定
钥匙两条铁律：乘法次数相加，加减次数不升（最高次项相消可能降，绝不可能升）。
步骤
1A·B 是九次 → A 与 B 的次数之和为 9。
2A+B 是五次 → 两式都不超过五次（若某个超五次，和必超五次）。结合"和为 9"：只能是 5 次 + 4 次。
3A−B：五次式减四次数，五次项没人跟它对消 → 一定是 5 次。
易错选 D 的想法是"万一最高项抵消"——但只有一个式子有五次项（另一个才四次），减法抵消需要同次对同次，抵不掉。
16平方差逆向答案：A
下列整式中，与 (−x−y) 相乘的结果为 x²−y² 的多项式是（　）
A. y−x　　B. x−y　　C. x+y　　D. −x−y
钥匙x²−y² = (x+y)(x−y)（平方差）。把 −x−y 提出一个负号：−x−y = −(x+y)。另一个因式就得是 −(x−y)。
步骤
1x²−y² = (x+y)(x−y)。
2−x−y = −(x+y)，所以另一个因式 = x²−y² ÷ (−(x+y)) = −(x−y) = y−x。
3验算：(−x−y)(y−x) = −xy+x²−y²+xy = x²−y² ✓ 选 A。
易错题干给的是 −x−y（不是 x−y 也不是 x+y）——先提负号再配方差，顺序反了就会错选 B 或 C。
17概念辨析答案：C
下列变形过程从左到右是因式分解的是（　）
A. (x+3)(x−3) = x²−9
B. 5m−5n−7 = 5(m−n)−7
C. a²−3a³ = a²(1−3a)
D. 3(x+y)(x−y)−6x = 3(x²−y²−2x)
钥匙因式分解的定义：整式的"和差"变成"积"，并且要分到不能再分。方向是"和→积"，展开是反方向。
步骤
1A：积 → 和差，是乘法展开，方向反了 ✗
2B：提出 5(m−n) 后还剩 "−7" 在外面相加，整体仍是和差形式，没分解到底 ✗
3C：a²−3a³ = a²(1−3a)，和差 → 积，且括号内 1−3a 无法再分 ✓
4D：等号右边是"3×( )”，其实还是积→和差的展开 ✗ 选 C。
易错B 的迷惑性最强：有括号、有公因式，但"整体"没变成纯积——判断标准看最后一步是和还是积。
18待定系数答案：B
已知二次三项式 2x²−mx−20 有一个因式 x+4，那么 m 的值是……（　）
A. 3　　B. −3　　C. 5　　D. −5
钥匙已知一个因式，就设另一个因式（首项对齐）：2x² 开头 → 另一因式必是 2x+k 形。
步骤
1设 2x²−mx−20 = (x+4)(2x+k)。
2常数项：4·k = −20 → k = −5。
3x 项系数：k + 4·2 = −5 + 8 = 3，即 −m = 3 → m = −3。
4所以二次三项式 = (x+4)(2x−5)，选 B。
验算展开 (x+4)(2x−5) = 2x²−5x+8x−20 = 2x²+3x−20，对照 2x²−mx−20 → m = −3 ✓

三、简答题（第 19–24 题）

考点：去括号 · 幂的运算链 · 完全平方推广 · 十字相乘 · 分组分解

19去括号合并答案：−2x²+2y²−5xy
计算：4xy−x²+y²−(x²−y²+9xy)
钥匙口诀：括号前是减号，进去符号全变。变完再合并。
步骤
1去括号：−(x²−y²+9xy) = −x²+y²−9xy。
2合并 x²：−x²−x² = −2x²。
3合并 y²：y²+y² = +2y²。
4合并 xy：4xy−9xy = −5xy。
5结果：−2x²+2y²−5xy。
易错括号里的"−y²"去掉括号后变"+y²"；"9xy"前是加号，去括号后变"−9xy"。三项都要翻号。
20幂运算链答案：−83m⁹
计算：(m²)³ · (2m)⁴ ÷ (−6m)
钥匙三条法则连用：幂的乘方指数乘（(m²)³=m⁶）；积的乘方各分配（(2m)⁴=2⁴m⁴）；同底相除指数减。
步骤
1(m²)³ = m2×3 = m⁶。
2(2m)⁴ = 2⁴·m⁴ = 16m⁴。
3m⁶·16m⁴ = 16m6+4 = 16m¹⁰。
416m¹⁰ ÷ (−6m) = −166m10−1 = −83m⁹。
易错(2m)⁴ = 2⁴m⁴ = 16m⁴，指数 4 也要给 2；除以 −6m 时负号和系数约分一步到位。
21偶次方去负答案：18a⁵−27a³+9a²
计算：(2a³−3a+1)·(−3a)²
钥匙先算乘方再分配：负数的偶次方是正数——(−3a)² = 9a²，负号没了！
步骤
1(−3a)² = (−3)²·a² = 9a²。
2分配律：2a³·9a² = 18a⁵；−3a·9a² = −27a³；1·9a² = 9a²。
318a⁵−27a³+9a²。
易错① 把 (−3a)² 算成 −9a²（丢"偶次方变正"）；② −3a·9a² 的指数是 1+2=3，不是 4。
22完全平方推广答案：a²+4b²+9c²−4ab+6ac−12bc
计算：(a−2b+3c)²
钥匙三项完全平方公式：(p+q+r)² = p²+q²+r²+2pq+2pr+2qr。把 −2b、+3c 整体当代入。
步骤
1平方项：a²、(−2b)² = 4b²、(3c)² = 9c²。
2交叉项 ×2：2·a·(−2b) = −4ab；2·a·3c = 6ac；2·(−2b)·3c = −12bc。
3合并：a²+4b²+9c²−4ab+6ac−12bc。
验算取 a=1, b=1, c=1：左边 (1−2+3)² = 4；右边 1+4+9−4+6−12 = 4 ✓
易错(−2b)² = 4b²（负号平方消失）；三个交叉项一个都不能漏——"每两项握一次手，共 3 次"。
23十字相乘答案：(x+12)(x−8)
因式分解：x²+4x−96
钥匙十字相乘口诀：积定常数，和定一次项。找两个数：乘起来 = −96，加起来 = +4。
步骤
1−96 的因数对里找"和为 4"：12 × (−8) → 12+(−8) = 4 ✓（一正一负，绝对值差要小）。
2x²+4x−96 = (x+12)(x−8)。
验算(x+12)(x−8) = x²−8x+12x−96 = x²+4x−96 ✓
易错常数 −96 是负的 → 两因数必一正一负；一次项 +4 → 正数的绝对值更大（12 > 8）。
24分组分解答案：(x−2y)(x+2y+3)
因式分解：x²+3x−4y²−6y
钥匙四项式先"二二分组"：前两项藏平方差，后两项藏公因式，两组要出现同一个因式才能再提。
步骤
1分组：(x²−4y²) + (3x−6y)。
2第一组平方差：x²−4y² = (x+2y)(x−2y)。
3第二组提公因式：3x−6y = 3(x−2y)。
4两组都有 (x−2y)，再提一次：(x−2y)(x+2y) + 3(x−2y) = (x−2y)(x+2y+3)。
验算展开：(x−2y)(x+2y+3) = x²+2xy+3x−2xy−4y²−6y = x²+3x−4y²−6y ✓
易错3x−6y = 3(x−2y)——公因式是 (x−2y)，不是 (x+2y)；分组方向取决于两组能否"对上号"。

四、解答题（第 25–29 题）

考点：整体代换 · 完全平方的和差关系 · 降次代换 · 错误分析建模 · 换元分解

25整体代换答案：−998
如果当 x=2 时，px³+qx+x⁰ 的值等于 1000，那么当 x=−2 时，px³+qx+x⁰ 的值是多少？
钥匙不必求 p、q！把 8p+2q 看成一个"整体"，x=−2 时它整体变号。x⁰ = 1（任何非零数的 0 次方）。
步骤
1x=2：8p+2q+1 = 1000 → 8p+2q = 999。
2x=−2：px³ = −8p，qx = −2q，x⁰ = (−2)⁰ = 1（还是 1！）。
3值 = −8p−2q+1 = −(8p+2q)+1 = −999+1 = −998。
易错① (−2)⁰ = 1，不是 0 也不是 −1；② 奇次方变号、偶次方不变号——x³ 与 x 都变号，x⁰ 不变。
26完全平方关系答案：xy=10；x+y=±7
已知 x−y=3，x²+y²=29，求（1）xy 的值；（2）x+y 的值.
钥匙完全平方的"加减 2xy"桥梁：(x−y)² = x²−2xy+y²、(x+y)² = x²+2xy+y²。条件在两式之间架桥。
步骤
1(x−y)² = 9 → x²−2xy+y² = 9。代入 x²+y²=29：29−2xy = 9 → xy = 10。
2(x+y)² = x²+2xy+y² = 29+2×10 = 49。
3x+y = ±7（平方是 49 的数有两个！）。
易错第(2)问漏 −7 是本题最大丢分点——开平方必须带 ±，除非题目另给 x、y 的符号限制。
27降次代换 · 侦探专题 ★★答案：1107（按更正版 x³）

🔍 数学侦探：一道"印错"的题

卷面原文：已知 x²−3x−504=0，求多项式 x²−2x²−507x+603 的值。按字面算会"算不下去"——侦探行动开始。

线索一
按卷面硬算		合并同类项：x²−2x² = −x²，原式 = −x²−507x+603。
代入条件 x² = 3x+504：
−(3x+504)−507x+603 = −510x+99
❌ 答案还拖着 x！"求值"没有定值——这条路不通。
线索二
题型的灵魂		这类"二次方程 + 求高次式值"的题，灵魂是降次代换：把 x² 换成 3x+504，把三次也降下来：
x³ = x·x² = x(3x+504) = 3x²+504x = 3(3x+504)+504x = 513x+1512
线索三
验证意图		若首项是 x³：
x³−2x²−507x+603 = (513x+1512)−2(3x+504)−507x+603
= (513−6−507)x + (1512−1008+603) = 0·x + 1107
✓ x 项恰好全部抵消！这是出题人精心设计的"指纹"。
结案这是一道印刷错误题：正确版本是 x³−2x²−507x+603（卷面把 ³ 误印成 ²，已确认）。
答案 = 1107。
学到什么① 降次代换：看到"已知二次方程求更高次式"就想到反复用 x²=3x+504；② x 项恰好全消（513−6−507=0）是这类题的"设计指纹"；③ 算不下去时不要硬算——回头检验题目，可能你看错了，也可能卷子印错了。用数学本身当"裁判"。

28错误分析建模答案：30
小马和小虎在 x=3，y=2 的条件下，计算多项式 A = ax³y²+bx²y⁴ 的值（其中 a、b 为常数）。小马将 3³ 算成了 9，得到结果为 22；小虎将 2⁴ 算成了 8，得到结果为 21。请计算正确的结果.
钥匙把每个人的错误翻译成一条方程：算错的那个"部件"换成错值，其余部分照正确算。两条方程解两个未知数 a、b。
步骤
1正确值的样子：A = a·27·4 + b·9·16 = 108a+144b。
2小马把 3³(=27) 算成 9：a·9·4 + 144b = 36a+144b = 22 ……①
3小虎把 2⁴(=16) 算成 8：108a + b·9·8 = 108a+72b = 21 ……②
4①÷2 得 18a+72b = 11（③）；②−③：90a = 10 → a = 1/9。
5代回③：72b = 11−2 = 9 → b = 1/8。
6正确结果 A = 108×19 + 144×18 = 12+18 = 30。
易错小马只错 3³，b·x²y⁴ 那部分他算的是正确值；小虎只错 2⁴。谁的错误就只影响含谁的部件——审题别张冠李戴。

五、材料阅读题（第 30 题）

材料核心恒等式：a²+b² = (a+b)²−2ab = (a−b)²+2ab —— 找出 a、b，一切照抄

30材料迁移 · 压轴(1) 120　(2) 130　(3) 2024
阅读材料：若 x 满足 (80−x)(x−60)=30，求 (80−x)²+(x−60)² 的值.
解：设 a=(80−x)，b=(x−60)，则 ab=30，a+b=(80−x)+(x−60)=20.
所以 (80−x)²+(x−60)² = a²+b² = (a+b)²−2ab = 20²−2×30 = 340。
根据上述阅读材料解决下列问题：
第(1)问
1若 x 满足 (30−x)(x−20) = −10，求 (30−x)²+(x−20)²。
2设 a=(30−x)，b=(x−20)：ab = −10，a+b = (30−x)+(x−20) = 10。
3a²+b² = (a+b)²−2ab = 10²−2×(−10) = 100+20 = 120。
易错ab = −10，代入 −2ab 时负负得正：−2×(−10) = +20。
第(2)问
1若 x 满足 (2019−x)²+(2017−x)² = 264，求 (2019−x)(2017−x)。
2设 a=(2019−x)，b=(2017−x)。这回给的是平方和，求积——用另一个形态：a²+b² = (a−b)²+2ab。
3a−b = (2019−x)−(2017−x) = 2（x 消掉了！这就是选这两个式子的原因）。
4264 = 2² + 2ab → 2ab = 260 → ab = 130。
易错材料里 a+b 直接给；这里改成 a−b = 2 也能用，因为 (a−b)² = a²−2ab+b² 同样搭桥。三个量 a+b、a−b、ab 知二求一。
第(3)问（压轴）
1如图：正方形 ABCD 边长为 x，AE=10（E 在 AD 上），CG=20（G 在 CD 上），长方形 EFGD 的面积是 481；NGDH、MEDQ 都是正方形，PQDH 是长方形，求四边形 MFNP 的面积。
2读图定长：ED = x−10（它同时是正方形 MEDQ 的边长），GD = x−20（正方形 NGDH 的边长）。
3长方形 EFGD 的面积 = ED×GD = (x−10)(x−20) = 481。
4大四边形 MFNP 是正方形，边长 = (x−10)+(x−20) = 2x−30（左边的 ME 加下边的 FN 拼出来）。
5设 a = x−10，b = x−20：a−b = 10，ab = 481，MFNP 边长 = a+b。
6SMFNP = (a+b)² = (a−b)²+4ab = 10²+4×481 = 100+1924 = 2024。
钥匙第(3)问是材料方法 + 第 14 题拼图思想的合体：(a+b)² = (a−b)²+4ab——不知道 a、b 各是多少没关系，差与积就够了。
验算另一条路：由 (x−10)(x−20)=481 得 x²−30x+200=481 → x²−30x=281；(2x−30)² = 4x²−120x+900 = 4(x²−30x)+900 = 1124+900 = 2024 ✓ 两条路同答案。
易错① 把 MFNP 当长方形——沿 ME 与 FN 走一圈会发现四边相等，它是正方形；② 只想解方程求 x——x²−30x=281 在七年级解不了，整体代换才是出路。
