一、选择题（第 1–6 题，每题 2 分）

考点：整式概念 · 幂运算 · 乘法公式辨析 · 次数分析 · 拼图代数

1概念辨析答案：C
下列说法正确的是（　）
A. −ab³5 不是整式　　B. 6m²n7 的系数是 6，次数是 3
C. 0 是单项式　　D. x⁴+y²−3 是六次三项式
钥匙逐项用定义检验：单项式=数字与字母的积（含单独一个数）；多项式=几个单项式的和。
步骤
1A：−ab³/5 是单项式（分母是数字 5），单项式是整式 → 说它"不是整式"错 ✗
2B：系数是 6/7（分数系数包含分子分母整体），次数 = 2+1 = 3 对，但系数说错了 ✗
3C：单独一个数也是单项式，0 是单项式 ✓
4D：次数取最高次项 x⁴（4 次），是四次三项式 ✗ 选 C。
易错① 分母是数字不影响"单项式"身份（分母含字母才是分式）；② 单项式次数 = 所有字母指数之和（m²n 是 2+1=3 次）；③ 多项式次数看最高项。
2幂运算答案：A
下列运算正确的是（　）
A. 2a²·a³ = 2a⁵　　B. (2ab²)³ = 6a³b⁵
C. a²+a³ = a⁵　　D. a⁶÷a² = a³
钥匙口诀三件套：乘指数加、除指数减、乘方指数乘；加法只能合并同类项。
步骤
1A：2a²·a³ = 2a2+3 = 2a⁵ ✓
2B：(2ab²)³ = 2³a³b2×3 = 8a³b⁶（系数也要立方）✗
3C：a² 与 a³ 不是同类项，加不起来 ✗
4D：a⁶÷a² = a6−2 = a⁴ ✗ 选 A。
易错积的乘方要每个因子都乘方（2³=8，不是 2×3=6）；这是 B 的陷阱。
3公式辨析 ★答案：D
下列算式中，适合运用完全平方公式计算的是（　）
A. (2a+b)(2a−b)　　B. (2a+b)(b−2a)
C. (2a+b)(a+2b)　　D. (2a+b)(−b−2a)
钥匙完全平方公式要求两因式完全相同或只差一个整体负号：先"提负号"把每个选项整理成"第一因式 vs 第二因式"再看。
步骤
1A：两个二项式一同一反（2a 同号、b 异号）→ 平方差 ✗
2B：b−2a = −(2a−b)，即 (2a+b) 与 (2a−b)——还是平方差 ✗
3C：字母对应都不一样（2a vs a+2b），什么公式都不是 ✗
4D：−b−2a = −(b+2a) = −(2a+b)，与第一因式 (2a+b) 只差负号 → (2a+b)(−b−2a) = −(2a+b)² = 完全平方 ✓ 选 D。
易错负号藏在整个括号前面时最迷惑：先提 −1 变形，"同同"= 完全平方、"同反"= 平方差。D 的 −b−2a 顺序也故意打乱（不是 −2a−b）。
4幂的方程答案：D
若 a、b 均为正整数，且满足 2ᵃ+2ᵃ+2ᵃ+2ᵃ = 2ᵇ×2ᵇ×2ᵇ×2ᵇ，则 a 与 b 的关系正确的是（　）
A. a=2b　　B. 2a=b+4　　C. a+2=b⁴　　D. a+2=4b
钥匙把"连加"翻译成"个数×"：4 个 2ᵃ = 4·2ᵃ = 2²·2ᵃ；把"连乘"翻译成"指数相加"。
步骤
1左边：2ᵃ+2ᵃ+2ᵃ+2ᵃ = 4·2ᵃ = 2²·2ᵃ = 2a+2。
2右边：2ᵇ×2ᵇ×2ᵇ×2ᵇ = 24b。
3同底幂相等 → a+2 = 4b。选 D。
易错别把右边写成 2⁴·2ᵇ——连乘是指数相加（b+b+b+b=4b），不是系数相乘。
5次数分析 ★答案：B
若整式 A 和整式 B 满足：整式 A+B 的次数是 5 次，则整式 A·B 的次数不可能是（　）
A. 12　　B. 11　　C. 10　　D. 9
钥匙和为 5 次有两种来源：普通相加（两式都 ≤5 次、至少一个 5 次）或最高次项相消（两式同次、首项相反）。乘法次数=两式次数之和。
步骤
1情形一（不抵消）：A 5次 + B ≤4次 → A·B 最多 5+5=10 次（B 也可以是 5 次）。可能：8, 9, 10 次（5+3、5+4、5+5）。
2情形二（6 次项相消）：A 6次 + B 6次，首项互消，和降到 5 次 → A·B = 6+6 = 12 次。
3枚举出的可能次数：8、9、10、12。11 不可能出现（奇数 11 = 5+6，但 5 次+6 次的和是 6 次，不满足条件）✓ 选 B。
易错只想"5+5=10"会漏 12；忘记"最高次项相消"这条隐蔽通道，就理解不了为什么 12 可能。手写参考答案旁的演算「x⁶+x⁵ → −x⁶+x⁵」正是"6 次相消降为 5 次"的实例。
6拼图代数 ★答案：D
用四个完全一样的长方形（长、宽分别设为 a、b）拼成如图所示的大正方形，已知大正方形的面积为 64，中间的小正方形的面积为 16，则下列关系式中不正确的是（　）
A. a+b=8　　B. a−b=4　　C. a·b=12　　D. a²+b²=64
钥匙两条腿走路：外看大正方形边长 a+b；内看中心小正方形边长 b−a。两个面积一给，a、b 全都能解。
步骤
1(a+b)² = 64 → a+b = 8（A 正确）。
2(b−a)² = 16 → b−a = 4 → a−b = −4？注意：图上 b＞a，所以 b−a=4，a−b=−4。B 说 a−b=4，若按图（b＞a）则 a−b=−4……参考答案勾了 B 为"正确"——本题问"不正确的是"，B 视为正确（等价 |a−b|=4 的口径，见易错提醒）。
3平方差桥梁：4ab = (a+b)² − (b−a)² = 64−16 = 48 → ab = 12（C 正确）。
4a²+b² = (a+b)² − 2ab = 64 − 24 = 40 ≠ 64 → D 不正确 ✓ 选 D。
易错① 选项 B 的坑：图上 b＞a 时 a−b=−4，但四个选项只有 D 是明显错的（参考答案口径：B 按 |a−b|=4 视为正确，考试以老师口径为准）；② 真正考点是 D——别把"a²+b²"当成"(a+b)²=64"。
验算a+b=8、ab=12 → a、b 是 6 和 2（或 2 和 6）。a²+b²=36+4=40 ✓；大正方形 8²=64 ✓；小正方形边 b−a=4（取 b=6,a=2）→ 16 ✓ 全部吻合。

16规律探索答案：3n−1

17幂=1 三分支 ★头号陷阱答案：−2026、−1、−2
阅读材料：①1 的任何次幂都等于 1；②−1 的奇数次幂都等于 −1；③−1 的偶数次幂都等于 1；④任何不等于零的数的零次幂都等于 1。

钥匙"幂=1"有三个来源：底数=1、指数=0（底≠0）、底数=−1 且指数为偶数。每个来源单独解，互不干扰。
步骤
1来源①（底=1）：2x+3 = 1 → x = −1（指数 x+2026=2025，任何数都行）。
2来源④（指数=0，底≠0）：x+2026 = 0 → x = −2026；检验底数 2×(−2026)+3 = −4049 ≠ 0 ✓。
3来源③（底=−1，指数为偶）：2x+3 = −1 → x = −2；指数 = −2+2026 = 2024（偶数）✓ → x = −2。
验算三个值分别代入：(−1)²⁰²⁵ 底=1 ✓；(−4049)⁰=1 ✓；(−1)²⁰²⁴=1 ✓。
易错① 漏"指数=0"这条最常见（忘了零次幂）；② 解出底=−1 后必须验指数的奇偶——若是奇数，(−1)奇=−1 不成立；③ 别把三个 x 混在一处解，一条来源一个方程。
18双正方形 ★设计巧妙答案：40492
如图，点 C 是线段 AB 上的一点，分别以 AC、BC 为边在 AB 的同侧作正方形 ACDE 和正方形 CBFG，连接 EG、BG、BE．当 BC=1 时，△BEG 的面积记为 S₁；当 BC=2 时，记为 S₂；……当 BC=n 时，记为 Sₙ，那么 S₂₀₂₅−S₂₀₂₄ 的值为 ＿＿＿.
钥匙这类"随 n 变化的面积"题：先用代数求出 Sₙ 的通式，再作差。设 AC=x、BC=n，把 △BEG 看成"两个正方形 − 三块三角形"。
步骤
1坐标定位：A(0,0)、C(x,0)、B(x+n,0)、E(0,x)、D(x,x)、G(x,n)、F(x+n,n)。
2面积分解：S△BEG = S□ACDE + S□CBFG − S△EDG − S△AEB − S△GFB。
3逐个算：S△EDG = ½·x·(x−n)（底 ED 长 x，G 到 ED 距离 x−n）；S△AEB = ½·x·(x+n)；S△GFB = ½n²。
4Sₙ = x²+n² − ½x(x−n) − ½x(x+n) − ½n² = x²+n²−½x²+½nx−½x²−½nx−½n² = ½n²——x 全部消掉！
5S₂₀₂₅−S₂₀₂₄ = ½(2025²−2024²) = ½×(2025+2024)×(2025−2024) = ½×4049×1 = 4049/2。
验算鞋带公式直接算 △BEG（E(0,x)、G(x,n)、B(x+n,0)）：S=½|x(n−0)+x(0−x)+(x+n)(x−n)| = ½|x²−n²−x²+x²−n²+…|= ½n² ✓ 与分解法一致。
易错① "与 x 无关"是本题的设计灵魂——别死盯着图上比例；② 平方差 2025²−2024² 别硬算，拆成 (2025+2024)(2025−2024)。

19混合运算(1) −¼x⁶y³　(2) 16x²−9y²−6yz−z²

(1) 步骤
1乘方先走：(−½x²y)³ = −⅛x⁶y³；(−2y²)³ = −8y⁶。
2乘法：3x²y⁵·(−⅓x⁴y⁴) = −x⁶y⁹（系数 3×(−⅓)=−1，指数加：2+4=6、5+4=9）。
3除法：系数串从左到右 (−3)×(−⅓)÷(−8) = 1÷(−8) = −⅛；字母串 x2+4=x⁶、y5+4−6=y³ → 第二项 = −⅛x⁶y³。
4合并同类项：−⅛x⁶y³ − ⅛x⁶y³ = −¼x⁶y³。
易错① (−2y²)³ 别算成 −2y⁶ 或 −6y⁶——系数也要立方：−8y⁶；② 符号链长，每一步只动一个符号，逐步写清；③ 负负得正、正负得负，结尾统一检查。
验算取 x=1、y=1 代入原式：(−½)³ − 3·(−⅓) ÷ (−2)³ = −⅛ − (−1)÷(−8) = −⅛ − ⅛ = −¼ ✓（与答案 −¼x⁶y³ 代入同值）。
(2) 步骤
1找"相同与相反"：4x 相同；(3y+z) 与 (−3y−z) 互为相反 → 平方差结构。
2(4x+3y+z)(4x−3y−z) = [4x+(3y+z)][4x−(3y+z)]。
3= (4x)² − (3y+z)² = 16x² − (9y²+6yz+z²)。
4= 16x²−9y²−6yz−z²。
易错去括号时 (3y+z)² 的中间项 6yz 别丢，负号只提一次。
20因式分解(1) (x−y)(x−y+2)(x−y−2)　(2) 4(4a+b)(a+4b)

(1) (x−y)³+4(y−x)　　(2) 25(a+b)²−9(a−b)²
(1) 步骤
1统一底数：y−x = −(x−y) → 原式 = (x−y)³ − 4(x−y)。
2提公因式 (x−y)：= (x−y)[(x−y)²−4]。
3平方差：= (x−y)(x−y+2)(x−y−2)。到这一步就不能再分了（一次因式）。
易错(y−x) 变 −(x−y) 时 4 前的加号跟着变减号——这是本题第一关卡。
(2) 步骤
1整体平方差：[5(a+b)]² − [3(a−b)]²。
2= [5(a+b)+3(a−b)][5(a+b)−3(a−b)]。
3化简两因式：(8a+2b)(2a+8b)。

22整体消参 ★答案：8
已知关于 x 的整式 (3a⁴x−2)−(9x+3) 的值与 x 无关，求整式 (a−1)(a+1)(a²+1)(a⁴+1) 的值.
钥匙"与 x 无关" → 化简后 x 的系数 = 0，解出 a⁴；再对目标式连续平方差。
步骤
1化简：3a⁴x−2−9x−3 = (3a⁴−9)x − 5。
2与 x 无关 → 3a⁴−9 = 0 → a⁴ = 3。
3目标式链式平方差：(a−1)(a+1) = a²−1；再乘 (a²+1) = a⁴−1；再乘 (a⁴+1) = a⁸−1。
4a⁸ = (a⁴)² = 9 → a⁸−1 = 8。
易错别试图解出 a 本身（a=⁴√3 超纲）——把 a⁴ 当整体就够了；连乘时一对一对地套平方差，不是一锅端。

（2）小明验算第三个等式时写：5²−4×6 = 5²−(5−1)×(5+1) = 5²−(5²−1) = 1，他的依据是哪个乘法公式？＿＿＿；请用字母 a、b 表示这个公式 ＿＿＿；

24双正方形阴影 ★(1) ½(a²−ab+b²)　(2) 263
如图，已知正方形 ABCD 的边长为 a，正方形 BEFG 的边长为 b，且 a＞b，点 G 在边 BC 上，连接 AF，交 BG 于点 H，连接 DH．
(1) 求阴影部分的面积 S阴（用含 a、b 的代数式表示）；
(2) 连接 BF，当 AE=8，三角形 ABF 的面积 S△ABF=7⁷⁄₉ 时，求阴影部分的面积 S阴．
钥匙AF 是"切割线"：两正方形的并集 = 阴影 + △ADH + △AEF（AF 下方的空白恰好是 △AEF，左上空白是 △ADH）。所以 阴影 = a²+b² − ½a² − ½(a+b)b。
(1) 步骤
1S△ADH：底 AD = a；H 在 BG 上（即 C 的正下方 x=a 处），到 AD 的水平距离也是 a → 面积 ½·a·a = ½a²。
2S△AEF：底 AE = a+b（A→B→E 共线），高 = EF = b → 面积 ½(a+b)b。
3S阴 = a² + b² − ½a² − ½(a+b)b = ½a² − ½ab + ½b² = ½(a²−ab+b²)。
4坐标复核（A 为原点）：C、G、H 共线于 x=a，阴影① = △DCH = a³/[2(a+b)]，阴影② = △GFH = b³/[2(a+b)]，和 = (a³+b³)/[2(a+b)] = (a²−ab+b²)/2 ✓ 殊途同归。
(2) 步骤
1AE = 8 → a+b = 8（AE = AB+BE）。
2S△ABF = 7⁷⁄₉ = 70/9 = ½·AB·（F 到 AB 的高）= ½ab → ab = 140/9。
3a²+b² = (a+b)² − 2ab = 64 − 280/9 = 296/9。
4S阴 = ½(a²+b²−ab) = ½(296/9 − 140/9) = ½·156/9 = 26/3。
易错① △ADH 的高是 a（H 的 x 坐标 = a），不是 b；② "S△ABF = ½ab" 的底高对应：底 AB=a、高=F 到直线 AB 的竖直距离=b——别拿 (a+b) 当底；③ a²+b² 别硬解 a、b，用 (a+b)²−2ab。
验算示意取 a=6、b=2：S阴 = ½(36−12+4) = 14；坐标法 S① = 216/16 = 13.5、S② = 8/16 = 0.5，和 = 14 ✓。且 (2) 问 a+b=8、ab=140/9 时 S阴 = ½(296/9−140/9) = 78/9 = 26/3 与手写参考答案一致 ✓
25对称恒等式 · 印误专题 ★(1) 见解析　(2) 12（按更正版 c）
利用我们学过的知识，可以导出下面这个形式优美的等式：
a²+b²+c²−ab−bc−ac = ½[(a−b)²+(b−c)²+(a−c)²]
该等式从左到右的变形，不仅保持了结构的对称性，还体现了数学的和谐、简洁美。
（1）请你验证该等式的正确性。
（2）利用上述等式，解决下面的问题：若 a=2026x+2000，b=2026x+2002，卷面此处印作「b」＝2026x+2004，求整式 a²+b²+c²−ab−bc−ac 的值.
印误警报第 (2) 问第三个式子的变量印成了 b（与前一个重复），但等式 a²+b²+c²−ab−bc−ac 里有 c；且三个式子间隔均匀（2000→2002→2004，每次差 2）的三连设计，说明它显然是 c=2026x+2004。手写参考答案也按 c 计算。以下按更正版 c 求解。
(1) 验证
1右边 = ½[(a²−2ab+b²)+(b²−2bc+c²)+(a²−2ac+c²)]。
2= ½[2a²+2b²+2c²−2ab−2bc−2ac]。
3= a²+b²+c²−ab−bc−ac = 左边 ✓ 等式成立。
(2) 步骤
1(a−b)² = (2026x+2000−2026x−2002)² = (−2)² = 4。
2(b−c)² = (2026x+2002−2026x−2004)² = (−2)² = 4。
3(a−c)² = (2026x+2000−2026x−2004)² = (−4)² = 16。
4原式 = ½(4+4+16) = ½×24 = 12。
易错x 全部消掉是设计核心——不要去解 x；三个差分别是 −2、−2、−4，平方是 4、4、16，最后别忘乘 ½。
验算取 x=0：a=2000、b=2002、c=2004。a²+b²+c²−ab−bc−ac = 2000²+2002²+2004²−2000×2002−2002×2004−2000×2004 = (4000000+4008004+4016016)−(4004000+4012008+4008000) = 12024020−12024008 = 12 ✓
26阅读理解 · 类比探究 · 压轴 ★★(1) 2560　(2) 31　(3) 1026　(4) 3636
阅读材料：若 x 满足 (60−x)(x−40)=20，求 (60−x)²+(x−40)² 的值.
解：设 60−x=a，x−40=b，则 ab=20，a+b=(60−x)+(x−40)=20.
所以 (60−x)²+(x−40)² = a²+b² = (a+b)²−2ab = 20²−2×20 = 360.
【类比探究】（1）若 x 满足 (70−x)(x−20)=−30，求 (70−x)²+(x−20)² 的值；
（2）若 x 满足 (3−4x)(2x−5)=9/2，求 (3−4x)²+4(2x−5)² 的值；
（3）若 x 满足 (2023−x)²+(2020−x)²=2061，求 (2023−x)(2020−x) 的值；
【解决问题】（4）如图，正方形 AEGO 和长方形 KLMC 重叠，重叠部分是长方形 BEFC 其面积是 300，分别延长 FC、BC 交 AO 和 OG 于 D、H 两点，构成的四边形 ABCD 和 CFGH 都是正方形，四边形 ODCH 是长方形．设 CM=x，KC=3CM=3x，KB=54，FM=20，延长 AO 至点 P，使 OP=2OD，延长 AE 至 R，使 RE=2BE，分别过点 P、R 作 AP、AR 垂线，两垂线交于点 N，求正方形 ARNP 的面积.（结果是一个具体的数值）
钥匙材料灵魂一句话：a+b、a−b、ab、a²+b² 四个量，知二求一——桥梁是 (a+b)² = a²+b²+2ab = (a−b)²+4ab。每个小问先"设 a 设 b"，再挑顺手的两条腿。
(1) 步骤
1设 a=70−x，b=x−20：ab=−30，a+b = 50。
2a²+b² = (a+b)²−2ab = 2500−(−60) = 2560。
易错ab 是负三十！−2ab = −2×(−30) = +60，负负得正。
(2) 步骤
1设 a=3−4x，b=4x−10=2(2x−5)（把系数 2 吸进 b，正好把 4(2x−5)² 变成 b²！）。
2ab = (3−4x)(4x−10) = 2×(3−4x)(2x−5) = 2×9/2 = 9（题给 (3−4x)(2x−5)=9/2）。
3a+b = (3−4x)+(4x−10) = −7。
4目标式 = a²+b² = (a+b)²−2ab = 49−18 = 31。
易错这是全卷最妙的一设：把 4(2x−5)² 的系数 4 开平方吸进 b（b=2(2x−5)），目标式就干净地变成 a²+b²——设谁，是奔着目标式长什么样去设的。
(3) 步骤
1设 a=2023−x，b=2020−x：a²+b²=2061（题给），a−b = 3。
2(a−b)² = a²+b²−2ab → 9 = 2061−2ab。
32ab = 2052 → ab = 1026。
(4) 压轴步骤
1读图定长（以 A 为原点、AR 竖直向下）：AB = KC−KB = 3x−54（正方形 ABCD 的边）；BE = CM−FM = x−20（重叠长方形 BEFC 的宽，也即正方形 CFGH 的边 CF）。
2BEFC 面积 = AB×BE = (3x−54)(x−20) = 3(x−18)(x−20) = 300 → (x−18)(x−20) = 100。
3AR = AB+BE+ER = (3x−54)+(x−20)+2(x−20) = 6x−114 = 3[(x−18)+(x−20)]。
4设 a=x−18，b=x−20：ab=100，a−b=2 → a²+b² = (a−b)²+2ab = 4+200 = 204。
5SARNP = AR² = [3(a+b)]² = 9(a²+2ab+b²) = 9(204+200) = 3636。
易错① "面积 300" 对应 (3x−54)(x−20) 而不是 (x−18)(x−20)——先把 3 提出来再设 a、b（这正是把 AR 凑成 3(a+b) 的伏笔）；② AR 是三条竖直段之和：AB+BE+ER，其中 ER=2BE；③ 别忘 ARNP 是正方形，S = AR²。
验算回代示意：由 (x−18)(x−20)=100 可解出真实 x（x²−38x+460=0 中的两根），但题目要的是具体数值且与 x 无关——因为 (a+b)² = a²+b²+2ab = 204+200 = 404 由 ab 与 a−b 唯一确定，无需知道 x。S = 9×404 = 3636 ✓ 与手写参考答案一致。
